Get started

There are no published installation images yet. This page explains how the first release will be built and what it will contain.

The base packages are being updated and tested. Install media will be built once the base system boots in a virtual machine.

What the install media will contain

A minimal image with the base metapackage. It boots with UEFI or BIOS, starts the s6 init system, brings up networking and gives you a shell.

  • Partitioning and filesystem tools: ext4, FAT, GPT (and more filesystems in the optional sets)
  • The pkgsrc package manager, pkgin
  • No compiler by default

Installing a development system

After installing the base system, add the development tools to build pkgsrc from source:

# install the development metapackage (once it is in a repository)
pkgin install base-devel

Building the install media yourself

The install image is produced from a root filesystem that has the base system installed in a staging directory. The build script is in the repository under src/mkiso/. It is a draft and has not been run yet.

LIMINE_BIOS_CD=/path/to/limine-bios-cd.bin \
LIMINE_UEFI_CD=/path/to/limine-uefi-cd.bin \
  ./src/mkiso/mkiso.sh ROOTFS KERNEL INITRD aalbus.iso

Requirements

Hardware requirements will be listed here once the first install image has been tested. Until then, assume a 64-bit x86 machine with a network connection.
