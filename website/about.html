About Aalbus

Aalbus is a hobby distribution built to explore diversity in the Linux ecosystem. It is not driven by license or language opinions. The name is a nod to Gentoo, Tux and Beastie.

How it differs from related systems

Aalbus is close to Chimera Linux in spirit: BSD userland, musl and LLVM. The main differences are the base and the package system.

  • Base: Aalbus builds on NetBSD's userland (nbase and pkgsrc), where Chimera uses FreeBSD's.
  • Packages: pkgsrc, where Chimera uses an Alpine-style packaging format.
  • Init: s6 with s6-openrc (in progress), where Chimera uses dinit with some systemd compatibility.

Design principles

Decentralized

The whole system is maintained in an extended pkgsrc tree. Anyone can take a copy of the distribution and run a complete package repository, so the project does not depend on any one person or server.

Minimal first

The default install is base: boot, network, filesystems, shell and the package manager. Compilers and build tools are optional and live in base-devel.

A different userland

Where there is a choice, Aalbus uses BSD, suckless and other non-GNU tools: nbase for coreutils, sed and grep, mksh for the shell, and libedit for line editing. GNU software is still available from pkgsrc when you need it.

Self-hosting

With base-devel, an Aalbus system can rebuild the pkgsrc tree from source, which keeps the distribution buildable on its own.

Current status

The base packages were last built in 2021 and are being updated. The install media and the installer are not finished yet. See the Get started page for what to expect in the first release.
