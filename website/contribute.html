Contribute

Aalbus is meant to grow from a personal project into one run by a community. Any kind of help is welcome.

Ways to help

Update packages

Many packages are still pinned to 2020–2021 releases. Pick one, find the latest upstream release, update the checksum and check that it builds.

Test the build

Run a pkgsrc bootstrap on your machine and report what breaks. Include the package name and the build log.

Write documentation

Installation notes, package guides and explanations of the design are all useful.

Host a mirror

Once repositories exist, a mirror is one of the most useful things you can run. See the packages page.

Where to talk

  • GitHub issues: bugs, packaging problems and feature requests.
  • Reddit: discussion and news.
  • Discord: chat with other contributors.

Reporting a build problem

Include the package name, the version, the platform, the exact command that failed, and the last 50 lines of the build log. Attach the full log as a file if it is long.
