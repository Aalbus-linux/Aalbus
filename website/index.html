Aalbus Linux

A small, experimental Linux distribution built from musl, the LLVM toolchain and mostly BSD-derived userland, managed with pkgsrc and run by s6.

Aalbus is pre-release. The base system is being rebuilt and no installation images are published yet. The packages page describes the plan.

What it is

Clean base

musl libc, LLVM/clang and libc++, and BSD and suckless tools (nbase from NetBSD, ubase, mksh). Where there is a choice, it prefers BSD and suckless tools over the GNU versions found on typical Linux systems.

Own init

s6, s6-rc and s6-linux-init for supervision and service management, with mdevd for device nodes and utmps for login records.

pkgsrc packages

Installed as binary packages with pkgin. Building from source is one metapackage away, so the same system can rebuild itself.

Decentralized by design

Anyone can run a package repository or a mirror. No single server, and no single maintainer, has to keep the distribution alive.

Two metapackages

Most users only need base: the runtime, the networking, the filesystem tools and the package manager. Developers add base-devel to build anything in pkgsrc from source.

MetapackageContains
baseBoot and init, networking, shell, core userland, filesystem tools, pkgin
base-develLLVM toolchain, make and configure tools, parser generators, git, perl, pkgsrc build dependencies
